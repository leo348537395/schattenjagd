# Schattenjagd

3D-Versteck-Shooter im Browser: 2 verstecken sich, 2 jagen.

- `server.js` – Spiel-Server (Node.js, keine Zusatzpakete): liefert die Seite aus und verbindet die Spieler in Räumen.
- `public/index.html` – das komplette Spiel.

Start lokal: `node server.js` und dann http://localhost:10000 öffnen.

Auf Render: neuer **Web Service** aus diesem Repository, Start-Befehl `node server.js`, Plan **Free**.
